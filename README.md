# CITY OUTLAW Browser Prototype

Lightweight 3D driving test build using Three.js. WASD/arrows drive, Space brakes, mouse drag looks around, R resets. Touchscreen controls are included.

## Deploy
Upload `index.html` and `README.md` to the root of your GitHub repository, then import the repository into Vercel as a static site. No build command is needed. If prompted, set the output directory to `.`.

This is an early browser prototype, not a complete GTA-style game or Android APK. Buildings and vehicle geometry are procedural placeholders.
